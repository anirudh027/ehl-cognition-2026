# Reference demo data

The local dashboard uses a small, deterministic PET hydrolase dataset so the demo does not depend on downloading large databases during a run.

- `petase_family.fasta`: UniProt entries A0A0K8P6T7, Q47RJ6, G8GER6, E9LVH9, F7IX06, and Q6A0I4.
- `5XJH.pdb`: RCSB PDB crystal structure of *Ideonella sakaiensis* PETase, X-ray diffraction at 1.54 Å.

Sources retrieved on 2026-08-22:

- https://rest.uniprot.org/
- https://www.rcsb.org/structure/5XJH
